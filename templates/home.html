About this site

Las Cruces sits between the Organ Mountains and the Rio Grande, and its brewery scene has grown alongside NMSU. Green chile beers show up on tap every fall during harvest season.

This site was built as a Flask project. Pages are Jinja templates that extend one base layout, and the brewery list comes from a live API call each time the page loads.

The code moves through three Git branches: development for new work, staging for testing, and production for the finished site.
